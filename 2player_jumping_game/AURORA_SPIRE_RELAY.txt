================================================================================
AURORA SPIRE RELAY  —  Form 3 Two-Player Jumping Game
Engine: tkinter + Pillow   (NO pygame needed)
================================================================================

HOW TO RUN (Thonny / school PC)
--------------------------------------------------------------------------------
1. Install Pillow once:
     Tools → Manage packages → search "Pillow" → Install
   Or terminal:
     pip install Pillow

2. Open this folder’s main program:
     aurora_spire_relay.py

3. Press F5 / Run.

4. Optional self-check:
     python aurora_spire_relay.py --verify

Files:
  aurora_spire_relay.py   ← main game (run this)
  jumping_game.py         ← short launcher that starts the same game
  requirements.txt        ← Pillow
  AURORA_SPIRE_RELAY.txt  ← this guide


CONTROLS
--------------------------------------------------------------------------------
Player 1:  A / D  move    W or SPACE  jump
Player 2:  ← / →  move    ↑  jump
Esc:       back to main menu
After a win: click "Restart Race"  (or press R / Enter / Space)


GAME MODES (start screen)
--------------------------------------------------------------------------------
1. Vertical Race      First courier to the SUMMIT star wins.
                      Overlay: "Player X Win! Time: 12.34 seconds"
                      + Restart Race button. Timer starts with the race
                      and STOPS when someone wins.

2. Co-op Climb        BOTH players must stand on the summit together.

3. King of the Hill   Last player who has NOT fallen wins.
                      Falling eliminates you in this mode only.

VIEW
--------------------------------------------------------------------------------
Shared Screen  (default)
Split Screen   (toggle on the start screen)


================================================================================
BRAINSTORM (invented match — NOT the teacher castle / wizard demo)
================================================================================
Theme:
  AURORA SPIRE RELAY
  Two polar couriers race up a frozen lighthouse under the northern lights.
  Ice ledges, frost gems, falling snowballs. No castle ruins. No teacher wizard.

Roles (3 — real stat differences):
  1. Blink Duelist  — high jump, medium speed; stomps apply a LONG stun
  2. Heavy Anchor   — slow + heavy; short jump; takes SHORTER stuns
  3. Gale Runner    — fastest run, lowest jump; best for pure racing lines

How modes feel per role:
  Race  → Gale Runner shines on long ledges; Blink Duelist skips gaps
  Co-op → Heavy Anchor can tank snowballs while the partner climbs
  KOTH  → Blink Duelist stomps to pressure; Heavy resists being stomped out

Theme power-up:  FROST GEM   → short speed burst + one extra air jump
Theme hazard:    SNOWBALL    → falling ice that stuns on hit
Shared screen default; split screen optional.
