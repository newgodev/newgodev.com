# Nebula Strike — Spaceship Fighter

Upgraded from the simple tkinter **Moving Box** demo into a full arcade space shooter.

## Run

```bash
pip install -r requirements.txt
python game.py
```

## Controls

| Key | Action |
|-----|--------|
| ← → / A D | Move |
| Space / Z | Fire |
| Shift | Boost (uses energy) |
| P | Pause |
| Enter | Start / restart |
| Esc | Quit / back to menu |

## Features

- Procedural neon ship, enemies, and FX (no image assets needed)
- Wave combat with 4 enemy types + escalating bosses
- Power-ups: Rapid Fire, Triple Shot, Shield, Health, Bomb
- Combo scoring, starfield parallax, screen shake, particle explosions
- Menu, pause, game over, and victory states
