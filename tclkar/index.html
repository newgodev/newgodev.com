由大綱寫成短講（書面語）

題目：你認為好朋友必須具備哪三種特質？為甚麼？
地圖用法：結構要清楚、一眼跟到路；用詞保持書面語實力，唔會改成淺白口語。
時間：不足一分鐘內容最高三分；準備五分鐘；慢講目標約一分半至兩分鐘。

一、完整大綱地圖（對齊全文）

開場→ 正直→ 誠實守信→ 見聞廣博→ 收尾

開場

  1. 打招呼、點題
  2. 提出三種特質：正直、誠實守信、見聞廣博
  3. 預告：以下說明原因
  4. 停頓

第一　正直

  1. 點出特質：正直
  2. 不會一味迎合；犯錯時誠實指出、幫助改正
  3. 影響：不致越走越偏；品德上成長
  4. 小結：故必須具備正直
  5. 停頓

第二　誠實守信

  1. 點出特質：誠實守信
  2. 說話可靠、答應的事會做到
  3. 影響：感到安心、願意互相信任；困難時有依靠
  4. 小結：故不可或缺
  5. 停頓

第三　見聞廣博

  1. 點出特質：見聞廣博
  2. 知識較豐富；帶來新想法與經驗
  3. 影響：一起進步、眼界更開闊；陪伴之外更助成長
  4. 小結：故亦必須具備
  5. 停頓

收尾

  1. 三者缺一不可
  2. 分述作用：走正路／建立信任／推動成長
  3. 升華：自己也應成為具備這些特質的人
  4. 結束、道謝

二、講稿（書面語 · 照讀）　／＝停頓

全文約 386 字

各位同學，大家好。我認為好朋友必須具備三種特質，分別是正直、誠實守信和見聞廣博。以下我會說明原因。／

第一是正直。正直的朋友不會一味迎合我們，看見我們犯錯，會誠實指出，幫助我們改正。有這樣的朋友，我們才不會越走越偏，也能在品德上成長。所以，好朋友必須具備正直的特質。／

第二是誠實守信。誠實守信的朋友說話可靠，答應的事會做到，令我們感到安心，也願意互相信任。在困難的時候，我們更需要這樣值得依靠的朋友。因此，誠實守信是好朋友不可或缺的特質。／

第三是見聞廣博。見聞廣博的朋友知識較豐富，常能帶給我們新的想法和經驗，使我們一起進步、眼界更開闊。好朋友不只陪伴我們，更應幫助我們成長。所以，見聞廣博也是必須具備的特質。／

總括而言，正直、誠實守信和見聞廣博缺一不可。正直助我們走正路，誠實守信建立信任，見聞廣博推動成長。交朋友時，我們也應努力成為具備這些特質的人。我的短講到此結束，謝謝大家。

三、怎樣用

  • 五分鐘準備：只抄「一」嘅編號要點，唔抄全文。
  • 正式講跟「二」讀；見紅色「／」就停兩至三秒。
  • 地圖對齊全文每一層意思；唔好臨時加動漫例子或改回口語。
