Type 2 conditional 第二類條件句

  • An imaginary situation now or in the future — not real.想像的情況,不是真的。
  • If + past simple, … would + verb
    If I knew the answer, I would tell you.
  • were for every person (was is also OK).were 較正式。
  • could / might = maybe → less certain. could = can (ability).could / might 表示「可能」;could 也可以表示「有能力」。
  • Advice: If I were you, I would …
  • Question: What would you do if you found a wallet?
  • Swap the two parts → same meaning. Comma only when “if” comes first.
  • Not past perfect: “If I had been …” is Type 3.

Reported instructions 轉述指令

  • Command → told. Request (please / can you) → asked.命令用 told,請求用 asked。
  • told / asked + person + to + verb
    “Close the door.” → Mum told me to close the door.
  • Negative: not to + verb (never write don't).
    “Don't run.” → The coach told us not to run.
  • Change the words: your → our / my, here → there, this → that, tomorrow → the next day, today → that day.代名詞、地點、時間都要轉。
  • Tenses in reported speech: am / is → was, will → would, can → could, has been → had been.
